# Festival Kuliner Nusantara 2026

Website sederhana untuk menampilkan informasi mengenai **Festival Kuliner Nusantara 2026**. Website ini dibuat menggunakan HTML sebagai latihan membuat struktur halaman web dengan berbagai elemen HTML seperti heading, navigation, table, image, list, dan form.

## Deskripsi

**Festival Kuliner Nusantara 2026** merupakan konsep website informasi acara kuliner yang menghadirkan berbagai makanan khas dari daerah di Indonesia.

Website ini memiliki tema:

> **"Nikmati Rasa, Kenali Budaya"**

Pengunjung dapat melihat informasi acara, kegiatan yang tersedia, jadwal festival, serta melakukan pendaftaran sebagai peserta.

## Fitur

* **Beranda**

  * Informasi nama acara
  * Tema acara
  * Penyelenggara
  * Deskripsi festival
  * Informasi tanggal, waktu, dan tempat
  * Gambar festival

* **Acara**

  * Food Bazaar
  * Cooking Demo
  * Pameran Kuliner Daerah

* **Jadwal**

  * Jadwal kegiatan berdasarkan hari dan waktu
  * Kategori kegiatan
  * Informasi pembukaan dan penutupan festival

* **Pendaftaran**

  * Nama lengkap
  * Email
  * Nomor telepon
  * Institusi / asal
  * Jenis kelamin
  * Tanggal lahir
  * Kategori peserta
  * Pilihan kegiatan
  * Kebutuhan khusus / informasi tambahan
